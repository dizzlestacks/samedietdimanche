        Visitor access · mode & overrides ▾

        1. Default page mode

        This is the public watch experience when preview override is off. Shop and Pre-order allow PayPal checkout for available watches; preview keeps public checkout disabled.

        Required for Pre-order mode. Shown on the watch page, in the cart and before payment. This is the shared shipping estimate also used by private preorder links.

        2. Preview override

        Shows watches without prices, regardless of the selected mode. Visitors can browse, favorite, save customizations and save watches to their cart. Enabled countdown and waitlist signup appear together above the watches. Public checkout and member early-access purchases stay disabled. Only valid private preorder link holders can bypass this preview when private watch preorders are enabled in Settings. Turn off to restore the selected mode and saved prices; pricing is never erased.

        3. Email signup availability

        Price-free preview always includes email signup so visitors can register their interest while customizing. Outside preview, the email signup setting controls the form. It never enables checkout.

        4. Member early access

        Members with a valid early-access link can browse and buy while the public page stays on the waitlist. Preview mode still blocks member early-access purchases. Private preorders are separate and managed in Settings. New signups receive a 7-day early-access link on screen. Use Get private link in the Waitlist tab to send a member a link manually; automated emails require email delivery setup. This switch does not open the public shop or turn email signup on.

        5. Women's section

        Adds a Men's / Women's choice when visitors can browse watches. The Women's section is currently empty. This does not open the catalog in waitlist mode. Turn off to hide Women's and return visitors to Men's.

        Apply mode, preview, early-access and Women's section changes with Save Changes at the top of this tab.
